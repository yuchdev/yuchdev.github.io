### FRED BROOKS AND TRIPLE EFFORS: WRITING CODE IS THE CHEAPEST, MAKING SOFTWARE IS NOT

Fred Brooks once noted that to turn code into a project you need roughly triple the effort. 
And to turn a project into a product, you need to triple again on top of that.

That equation hasn't changed.
What has changed is the coefficients.

Today, we ship faster, generate more code with AI, automate more pipelines - but the non-code parts have grown even heavier: architecture, workflows, CI/CD, security, UX, compliance, long-term maintenance and product support. 

Writing code is cheaper than ever.
Making software that actually works for people is not.
