###  SHUTUP 10

If you happen to use Windows, you always have options - the friction is mostly in defaults, not being enforced to use something. 

Automatic updates can be fully disabled or indefinitely postponed via Group Policy, registry keys, or PowerShell. Windows 10 made this less discoverable, but not impossible - standard practice in enterprise.

Bloatware and bundled UWP packages can be removed in one go with a single PowerShell script. I do it routinely if I deploy Windows VM.

Telemetry & intrusive features, data collection, consumer features, ads, and "suggestions" can be turned down or disabled entirely using policies/registry and tools like ShutUp10
