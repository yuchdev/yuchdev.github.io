### WHY WINDOWS IS NOT FOR COMFORT

I wouldn't say modern Microsoft Windows is built for comfort - at least not versions released after Windows 7

It's hard to feel "comfortable" in a system that shows ads despite being paid for, aggressively nudges you toward services you didn't ask for, and runs a non-trivial amount of opaque, intrusive background telemetry. Once you understand how deep that stack goes, comfort tends to be replaced by persistent insomnia 🙂

If we're talking about a truly user-friendly system - not just for casual users, but for people who actually build things - then MacOS comes much closer. The Unix foundation is coherent and consistent, the tooling is first-class out of the box, the UI doesn't actively fight you, and the system generally respects the boundary between "helpful defaults" and "forced decisions"

Linux, meanwhile, is built for control and performance, not comfort - but that's an honest trade-off. Modern Windows tries to sell itself as "comfortable" while steadily eroding user experience, and that mismatch is what makes it frustrating rather than comfortable.

Windows was never the problem. The problem (over time) became the defaults.
