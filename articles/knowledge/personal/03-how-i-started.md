### HOW I STARTED: WINDOWS 98 AND BSD

When I started, there wasn't really a choice - for me it was Windows 98. That "gentle slope" looked easy at first, but it quickly turned into a rabbit hole.
I learned there was a Registry full of critical state.
Windows Script Host automation long before PowerShell.
I ditched Explorer for tools like Far Manager.
Then came my first part-time IT job - web and mail servers, firewalls, LDAP.
And then I met my first Unix: FreeBSD 4.0.
For a long time, "Unix" meant no GUI at all, just a console - and that was perfectly fine. It taught me what mattered. When I later saw OS X, my reaction was
"Wow, BSD with a neat GUI"

Looking back, if I were starting today, I wouldn't begin with Windows or macOS or Linux at all.
I'd start with what they all share:

- kernel types and responsibilities
- user vs kernel space
- drivers and applications
- memory and paging
- processes and threads
- filesystems and permissions

That you can open a terminal and compile a C program on all of them.

Once you understand that common ground, the "cliff" disappears.

Different operating systems stop feeling like different worlds - they become different interfaces to the same underlying ideas.
